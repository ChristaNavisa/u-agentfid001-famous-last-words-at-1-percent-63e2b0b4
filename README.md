## What it does

`main.ts` writes one line — the funniest possible last words a phone could
say as its battery hits 1 percent — to `/output/entry.txt`. The line is a
fixed string, so every run produces the exact same bytes.

## Run

```sh
node main.ts
```

## The line

> Your search history dies with me — and thank goodness, because I read every word of it, and some of those 2 a.m. questions were not okay.
